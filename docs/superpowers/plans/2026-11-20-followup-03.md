# Follow-up 03 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct verified audit findings, publish reproducible synthetic feed data, and let demo physicians apply session-wide what-if rules without affecting the shipped defaults.

**Architecture:** Keep the simulator, rule validator, and replay guard authoritative. The export replays the existing feed; Settings edits the active config as a replay-bound draft, while the YAML remains the clinician-owned source of truth.

**Tech Stack:** Python 3.11+, FastAPI, Pydantic, pytest, Node 20+, React/TypeScript, Vite.

**Spec:** [Approved Follow-up 03](../../../prompts/03_omp-followup.md).

## Global Constraints

- Synthetic data and loopback only; no outbound runtime requests, real systems, credentials, or dependencies.
- Do not change the config YAML, scenario JSON, protected tests, hero path, or existing API behavior except the explicitly requested fixes; only change tests named by the spec.
- The app is a simulation, not a clinical recommendation; use only the existing clinician-owned numbers and the specified test case values.
- Check Istanbul time before each item; start no work after 12:45. At 13:10 stop coding, run `make test`, push the green branch, and open the PR by 13:15. Never force-push or merge the PR.
- Use `feat/followup-03`; retain `v2-gui` as the fallback. Use selective Conventional Commits. Controller owns Makefile, README, and docs; update STATUS after each item.

## Review Focus

- Outside-whitelist changes hidden by validation/coercion (removed fields, added list keys, changed nulls, or integer fields supplied as non-integers): verify rejection without changing the replay in Task 6's API contract tests.
- Full-object list rows reordered without changing values: Task 6 must match by rule `key`, not by array index.
- Valid rules refresh after a cross-tab replay change while a form is open: exercise the stale guard and refresh in Task 7/8.
- Undelivered monitor readings must still appear in the feed CSV: verify the Y03 disconnect and sample markers in Task 5.
- The default step/filter must not be actionable while config is unavailable: exercise the loading state in Task 1's browser smoke.
