60-second backup video and screenshots

The video and screenshots show the Turkish UI, the default recording. The English UI opens by default; the Turkish section below links to this same media.

Run it locally

Python 3.11+ and Node.js 20+ are required. From the repository root:

make setup
make demo

Then open http://127.0.0.1:8000. The UI opens in English; choose Settings → Language → Turkish for Turkish.
